# ysoserial

该项目作为当前静态分析检测 Java 反序列化漏洞研究中**广泛采用的基准（baseline）数据集**，被用于评估不同检测工具的有效性。
 工具性能的优劣主要体现在其**对该项目中已知存在漏洞的jar 包的检测能力**：一方面，是否能够准确检测出 **ysoserial 中已公开的已知漏洞调用链**；另一方面，是否能够在此基础上，进一步识别出**数据集中未显式列出的新型反序列化漏洞调用链**。

在项目文件夹下的`src/main/java/ysoserial/payloads/util`下，是所列出的已知的漏洞链，主要是一些**payload**，其注释部分有具体的漏洞调用链，**原项目注释中的调用链并不完全**，我对其进行了**修改与补充**，保证它所写出的调用链是完整，未出现断链。

该项目的md文档中给出了`Usage`，其`Dependencies`是被检测的一些库，如检测`CC3`,就是说`commons-collections:3.1`库中的漏洞，即`CommonsCollections1,3,5,6,7`是`CC3`已知的漏洞,共5条。
